Довідка WealthTracker

WealthTracker призначений для обліку доходів, витрат, накопичень і місячних бюджетів.

Початок роботи
1. Увійдіть під своїм обліковим записом.
2. На головній вкладці оберіть дохід або витрату, категорію, суму та дату. Натисніть «Додати».
3. Переглядайте операції, діаграми, накопичення та бюджет у відповідних вкладках.

F1 відкриває розділ для активної вкладки або вікна. Меню «Довідка» містить зміст і відомості про програму. Esc закриває вікно довідки.
Наведіть вказівник на поле або перейдіть до нього клавішею Tab, щоб побачити підказку. Унизу авторизованого вікна показано поточний логін та роль.
Довідка працює без Інтернету. Папка docs повинна бути поруч із програмою.
